# BestAIGen — Android (WebView)

Обёртка-приложение для https://perchance.org/bestaigen.

## Как получить APK (без Android Studio)

1. Создайте репозиторий на GitHub и загрузите в него **содержимое** этого архива
   (чтобы `settings.gradle.kts` лежал в корне репозитория).
2. Откройте вкладку **Actions** → workflow **Build APK** → он запустится сам
   (или нажмите **Run workflow**).
3. Когда сборка станет зелёной, откройте её и скачайте артефакт
   **BestAIGen-debug-apk** (внутри `app-debug.apk`).
4. Скопируйте APK на телефон и установите (разрешите установку из неизвестных источников).

## Если нужен другой адрес

Файл `app/src/main/java/com/bestaigen/app/MainActivity.java`, константа `START_URL`.

## Что умеет

- JavaScript, localStorage, cookies (в т.ч. сторонние — для iframe perchance)
- Выбор файлов (загрузка картинок)
- Скачивание: http(s), data: и blob: ссылки → папка «Загрузки»
- Полноэкранное видео, кнопка «Назад» ходит по истории
- Внешние ссылки открываются в браузере

## Важно

- Debug-APK подписан отладочным ключом: годится для личной установки.
  Для Google Play нужна release-сборка с вашим ключом.
- Данные WebView (настройки, локальная галерея) отдельны от браузера.
